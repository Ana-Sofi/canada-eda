# Canada EDA

Análisis exploratorio de series de tiempo de población y salud de Canadá.

## Cómo correrlo

```bash
git clone https://github.com/Ana-Sofi/canada-eda.git
cd canada-eda
pip install -r requirements.txt
```

Después abre `Canada_EDA.ipynb` y ejecuta todas las celdas. Los datos (`.csv` y `population.xlsx`) ya están en el repositorio.
